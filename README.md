# Mini NPU 학습장

MAC(Multiply-Accumulate) 연산과 `main.py`의 코드 구조를 브라우저에서 직접 실습하며 배우는 정적 웹 페이지입니다.

- 접속: https://jihyeongh21-svg.github.io/mini-npu-study/
- 내용: MAC 실험실(칸을 눌러 점수 확인), 코드 단계별 해부, data.json 실행 결과, O(N²) 시각화, 퀴즈
- 원본 코드와 문서: https://github.com/jihyeongh21-svg/mini-npu-simulator

빌드 과정 없이 `index.html` 한 파일로 동작합니다.
